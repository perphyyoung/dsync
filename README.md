# dsync: dir sync

跨目录层级、跨文件名的文件夹同步桌面应用：以内容哈希认定同一个文件。

## 功能

- 配对只认内容：两侧同哈希且各只有一个才配；同路径不同内容互相占位（不自动覆盖）；单侧多个相同内容标为重复
- 单向同步：声明一个方向，另一侧跟随（复制 / 改名 / 软删除）
- 结构对齐：把一侧的目录层级与命名套到另一侧
- 预览定型：点「向左/向右同步预览」即算好动作与统计，看清了再点「执行同步」；统计项前的复选框可整类取消或恢复
- 文件列表：左右各三列，显示路径、修改日期（到天）、大小；列头标出列名，点击列头按该列排序（升序 → 降序 → 默认）
- 左右互换：目录表头中间 `⇄` 一键互换，已扫描时结果前端同步翻转，不需要重扫
- 显示模式：全部 / 左侧 / 右侧 / 重复 / 占用 / 特殊，只看当前关心的行
- 扫描设置页：打开应用或点主界面「重新扫描」进入，集中配置左右目录与全部条件（目录层级、只含/排除关键字、只含/排除后缀、修改日期范围、文件大小、跳过隐藏文件）；「强制重算」是红色复选框，勾选时弹确认
- 主界面：扫描过滤行只读显示改过的条件摘要（无改动显示「无过滤条件，全量显示」）；显示过滤行细化列表（层级、关键字、后缀、日期、大小、跳过隐藏、隐藏一致、显示模式），超出扫描范围时弹「还原修改 / 重新扫描」
- 条件按目录对保存：扫描设置页显示最近 5 组（无滚动条），可搜索全部 100 组；左右目录互换命中同一组
- 删除一律软删除，进内置回收站，可还原；dsync 不做真正删除

## 数据

- 索引：两侧根目录的 `.dsync/dsync.db`（SQLite），记录配对关系与哈希缓存；删掉后重新扫描即可重建
- 回收站：软删除的文件移到 `.dsync/deleted/`，在界面「回收站」里还原
- 目录对档案：应用数据目录下的 `dir-pairs.db`（SQLite），最多 100 组，每组带自己的扫描条件；扫描设置页显示最近 5 组、可搜索全部
- 整个 `.dsync/` 不参与比较

## 使用

从 `release/dsync Setup x.y.z.exe` 安装后直接运行：

1. 启动即进入扫描设置页：左右各点「更改」选目录，已选的显示完整路径
2. 按需改条件，点「开始扫描」比较两侧；目录失效会留在本页告警，点「返回」不扫描
3. 点「向左同步预览」或「向右同步预览」：自动勾选该方向会执行的行，底部给出复制 / 改名 / 软删除 / 忽略的数量；统计项前的复选框可整类取消或恢复
4. 取消不需要的行，点红色「执行同步」落地

主界面：扫描过滤行只读显示已改动的条件摘要，最右侧「重新扫描」打开设置页；显示过滤行只细化列表，缩小直接刷新，扩大弹提醒且保留结果；表头「打开」在文件管理器中查看目录，中间 `⇄` 互换左右。

单行操作：中间操作列的 `<` / `>` 直接执行该行，`<` 以右为准改写左侧，`>` 以左为准改写右侧。文件右键可软删除或重算哈希。
