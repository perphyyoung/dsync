# dsync: dir sync

跨目录层级、跨文件名的文件夹同步桌面应用：以内容哈希认定同一个文件。

## 功能

- 内容哈希判定，不依赖路径与文件名
- 四级配对：索引记忆 → 相对路径 → 文件名 → 内容哈希
- 单向同步：选定基准侧，另一侧跟随（新增 / 修改 / 删除）
- 结构对齐：把一侧的目录层级与命名套到另一侧
- 过滤：最小大小、只含后缀、排除后缀
- 删除只进回收站，不永久删除

## 数据

索引保存在两侧根目录的 `.dsync/dsync.db`（SQLite），记录配对关系与哈希缓存。整个 `.dsync/` 不参与比较。删掉它后重新扫描即可重建。
