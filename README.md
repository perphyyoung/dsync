# dsync: dir sync

跨目录层级、跨文件名的文件夹同步桌面应用：以内容哈希认定同一个文件。

## 功能

- 内容哈希判定，不依赖路径与文件名
- 配对只认内容：两侧同哈希且各只有一个才配；同路径不同内容互相占位，不自动覆盖
- 单向同步：声明一个方向，另一侧跟随（复制 / 改名 / 软删除）
- 结构对齐：把一侧的目录层级与命名套到另一侧
- 过滤：最小大小、只含后缀、排除后缀
- 删除一律软删除，进内置回收站，可还原；dsync 不做真正删除

## 数据

索引保存在两侧根目录的 `.dsync/dsync.db`（SQLite），记录配对关系与哈希缓存；软删除的文件进 `.dsync/deleted/`。整个 `.dsync/` 不参与比较。删掉索引后重新扫描即可重建。

## 使用

选左右两个目录 → 扫描 → 按行 `<` / `>` 同步，或勾选后点「向左同步预览」/「向右同步预览」再执行。

```bash
pnpm install
pnpm dev
```

```bash
pnpm release
```
